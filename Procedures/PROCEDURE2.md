# Week 02 - Validate board fixtures

## Aim

Validate abstract card identifiers and a small set of classroom state labels.

## Procedure

1. Check one out-of-range slot and one accepted slot.
2. Check the deliberately unknown state label.
3. Print only deterministic acceptance/rejection messages.
4. Compile, run, and compare `OUTPUT.txt`.

## Scope boundary

Slots and states are artificial learning fixtures; they are not real schedules or operational data.
