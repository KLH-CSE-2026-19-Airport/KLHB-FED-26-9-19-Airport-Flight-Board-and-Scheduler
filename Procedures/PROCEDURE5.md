# Week 05 - Board methods

## Aim

Use named methods to render a fixture card and validate its state label.

## Procedure

1. Implement a `showCard` rendering method.
2. Implement a `knownState` predicate.
3. Invoke both with fixed abstract fixture values.
4. Compile, run, and compare `OUTPUT.txt`.

## Scope boundary

The card label and state are fabricated classroom values, not real flight or timetable information.
