# Week 07 - Edge cases

## Aim

Use a set to reject a duplicated fixture card and check fixed board capacity.

## Procedure

1. Add three permitted card IDs to a `LinkedHashSet`.
2. Attempt to add the first fixture again.
3. Check that the total does not exceed the exercise capacity of three.
4. Compile, run, and compare exact output.

## Scope boundary

This protects a classroom fixture list only; it does not control a public board or transport system.
