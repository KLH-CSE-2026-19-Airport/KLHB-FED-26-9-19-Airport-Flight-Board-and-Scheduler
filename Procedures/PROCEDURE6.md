# Week 06 - Array search

## Aim

Search a short array of three invented board-card IDs.

## Procedure

1. Define an ordered array of the three card fixtures.
2. Implement linear search returning either an index or `-1`.
3. Search once for an existing card and once for a missing card.
4. Verify the console output.

## Scope boundary

This is local array practice and cannot retrieve real schedules or operational records.
