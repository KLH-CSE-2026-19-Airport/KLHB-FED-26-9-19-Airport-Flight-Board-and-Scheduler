# Week 09 - Board-card objects

## Aim

Represent one abstract board-card fixture with a Java class and object.

## Procedure

1. Define `BoardCard` with only ID, label, and state fields.
2. Create one invented fixture card.
3. Override `toString` to make the object visible in the console.
4. Compile, run, and compare output proof.

## Scope boundary

The object contains no real airline, traveller, itinerary, location, or timing data.
