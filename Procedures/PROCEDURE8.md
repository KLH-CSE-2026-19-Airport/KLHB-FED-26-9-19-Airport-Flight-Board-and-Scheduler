# Week 08 - Recursive ready-state count

## Aim

Use recursion to count ready states in three static fixture cards.

## Procedure

1. Create an array with two `READY` entries and one `HELD` entry.
2. Define an end-of-array base case.
3. Accumulate matching entries recursively.
4. Compile, run, and compare with `OUTPUT.txt`.

## Scope boundary

The recursive count is classroom-only analytics, not live information.
