# Week 04 - Loop-driven board actions

## Aim

Use an enhanced `for` loop to display a fixed sequence of learning actions.

## Procedure

1. Store three fixture action lines in a string array.
2. Traverse the array with an enhanced loop.
3. Print an explicit deterministic end marker.
4. Compile, run, and compare with `OUTPUT.txt`.

## Scope boundary

The actions simulate console learning steps and do not update a real board or schedule.
