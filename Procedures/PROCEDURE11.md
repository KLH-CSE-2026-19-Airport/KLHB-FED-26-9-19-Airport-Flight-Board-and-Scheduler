# Week 11 - Fictional CSV storage

## Aim

Write and load a local CSV file containing three invented board-card fixtures.

## Procedure

1. Create a header and three synthetic card rows.
2. Write them to `board-fixtures.csv` in this folder.
3. Read back the same file and print the first fixture row.
4. Commit the generated CSV after output verification.

## Scope boundary

The CSV contains artificial labels and state values only; no real schedule, travel, or personal data is stored.
