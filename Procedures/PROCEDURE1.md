# Week 01 - Board-state baseline

## Aim

Create a compact Java baseline for an invented classroom board of three state cards.

## Procedure

1. Define a simulator title and fixed card count.
2. Print the first fictitious card state.
3. Compile and run the class from this folder.
4. Compare the console result with `OUTPUT.txt`.

## Scope boundary

This is a classroom board-state simulator. It is not a flight, airport, travel, schedule, ticket, passenger, tracking, or location system.
