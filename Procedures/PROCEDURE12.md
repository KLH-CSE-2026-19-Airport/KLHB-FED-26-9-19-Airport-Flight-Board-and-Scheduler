# Week 12 - Collections and final report

## Aim

Use an `ArrayList` and stream filters to report the synthetic board-state distribution.

## Procedure

1. Add three fictional state cards to an ordered list.
2. Count `READY` and `HELD` cards with stream filters.
3. Print a deterministic final report.
4. Compile, run, and compare with `OUTPUT.txt`.

## Scope boundary

The report is exercise analytics only and does not represent a live airport or flight-information service.
