# Week 03 - Decision rules

## Aim

Use a Java `switch` expression to retain known classroom board states.

## Procedure

1. Define three permitted fixture states.
2. Normalise two known state examples using `switch`.
3. Print each fixed card and its resulting state.
4. Run and compare the exact output proof.

## Scope boundary

The decision rule is only for generic state cards and has no relationship to a real flight board.
